# HMSC Experiments Replication Package Website

Open `index.html` in a web browser.

The `data/` directory contains the original replication package files copied unchanged from the supplied ZIP archive, plus the supplied paper PDF. The `pages/` directory contains uniformly styled HTML renderings of the Word documents.

Site navigation and generated explanatory text use British English. Converted Word-document content is kept as rendered from the originals to avoid altering the evidence.



Generation statement: the landing page records that the site was generated using GPT and includes the explicit user query.
